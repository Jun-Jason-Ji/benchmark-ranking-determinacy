# Execution-only amendment before collection

The independent statistical review identified that the historical evaluator overwrites the generic per-policy summary when a second setting runs. Before any new study outcome was collected, the wrapper was amended to preserve separately named metadata and actual built-controller summaries after every setting. The orchestrator also enforces the remaining technical time budget on each process, rather than checking only at launch.

The original frozen manifest and the two execution scripts are retained with `v1_before_collection` names. The replacement frozen manifest pins these two execution changes. Seeds, hypotheses, block count, outcomes, analysis and stopping rules are unchanged. No original result or server implementation was modified.

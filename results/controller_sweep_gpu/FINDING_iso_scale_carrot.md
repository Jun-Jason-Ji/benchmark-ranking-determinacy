# 发现：胡萝卜任务上两策略差值沿校准不可见的尺度轴单调反转（2026-09-18，24 集/条件）

平台与协议：`results/controller_sweep/PROTOCOL.md`；GPU 后端（WSL2, jax 0.5.3）；预设 `iso_ratio_v1`（刚度与阻尼同乘 c）。校准侧已证明这些条件在 40 条真实示范的自由空间回放里逐点差 < 0.14 mm（`results/replay_sysid/grid/iso_invariance.md`）。

| 尺度 c | octo-small | octo-base | Δ = small − base（配对） | 95% 区间 |
|---:|---:|---:|---:|---|
| 0.25 | 1/24 | 3/24 | −0.083 | [−0.21, 0.00] |
| 0.5 | 2/24 | 5/24 | −0.125 | [−0.25, 0.00] |
| 1（48 集） | 6/48 | 7/48 | −0.021 | [−0.15, +0.10] |
| 2 | 4/24 | 4/24 | 0.000 | [−0.17, +0.17] |
| 4 | 5/24 | 2/24 | +0.125 | [0.00, +0.25] |

- Δ(c=4) − Δ(c=0.5) = +0.250，配对自助 95% [+0.08, +0.46]：**差值的变化有区间支持**。
- Δ(c=4) − Δ(c=0.25) = +0.208 [+0.04, +0.38]。
- 尺度指数与逐集 Δ 的相关 +0.238，置换检验 p = 0.015：单调趋势成立。
- 两端各自的 Δ 符号区间刚触零：按协议属"候选翻转"，尚不是"区间支持的翻转"。

机制上的解读：软控制器（c 小）下 octo-base 相对占优，硬控制器（c 大）下 octo-small 相对占优；两者在标称处几乎打平。自由空间校准对 c 完全无感，因此校准后的"最优参数"无法决定该任务上该选哪个策略。这是方案定义的决策相关歧义的直接实例，且拟合相等由构造保证，不需统计检验。

后续：队列第二阶段把等比条件补到 48 集；`scripts/queue_iso_extreme96.cmd` 在总队列结束后把 c ∈ {0.25, 0.5, 4} 补到 96 集，并重算区间。若两端区间分别离开零，即为区间支持的翻转，作为图 1 主案例；否则以"差值变化区间支持 + 单调趋势"作为主证据，翻转本身标为待确认。

Δ(4) − Δ(0.5) = +0.062 [−0.03, +0.17]；趋势 p = 0.64。按 24 集分块的 Δ：c=0.5 为 −0.125, −0.125, −0.042, +0.042；c=4 为 +0.125, 0.000, −0.042, −0.083。前两块的"反转"在后两块完全回归。

**结论：胡萝卜任务上两策略差值不随刚度/阻尼共同尺度变化；此前的候选符号翻转与 48 集时的"c=0.5 下 base 优"均为样本量不足造成的波动，予以撤回。** 预注册协议（两端各自区间支持才算翻转）正确地阻止了过早声称。

方法学教训：两策略成功率均在 0.1 附近时，96 集配对差的 95% 半宽仍约 0.08；要以 80% 功效检出 Δ = 0.1 的变化需要数百集。低成功率任务不适合做排序敏感性研究，后续应选成功率在 0.3–0.7 之间的任务或策略对。

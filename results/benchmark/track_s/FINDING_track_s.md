# 发现：判定方法的覆盖率模拟（基准赛道 S，2026-09-19 01:40）

配置：`benchmark/README.md` 赛道 S；300 次重复 / 单元；相容带 |s| ≤ 2.5（与 `analyze_response_surface_v2.py` 相同，向采样范围 ±2 外各外推 0.5）。逐单元表见 `track_s_summary.md`，图 `fig_track_s.png`。

|---|---|---|---|---|
| 平坦 | 0.92 / 0.05 / 0.53 | 1.00 / 0.00 / 0.24 | 1.00 / 0.00 / 0.14 | 1.00 / 0.00 / 0.15 |
| 线性 | 0.24 / 0.36 / 0.71 | 0.99 / 0.00 / 0.29 | 0.95 / 0.00 / 0.15 | 0.95 / 0.00 / 0.19 |

（"宣布率"为真值可判定的单元上的平均，含 n = 24 与小 Δ₀ 的低功效单元；单元级数字见 `track_s_summary.md`。）

## 四条结论

1. **点校准的误判率随集数上升。**在任何非平坦曲面上，标称条件的区间只覆盖 Δ(0) 而非带内极值；n 从 24 到 96，线性曲面 Δ₀ = 0.1 的误判率 0.13 → 0.36，采样点凹陷 Δ₀ = 0.2 的误判率 0.26 → 0.88。这是"更多集数让错误结论更自信"的定量版本，也是论文动机图的合适素材。
2. **并集界在"极值位于采样条件"时有效且功效最高**（覆盖 ≥ 0.98，误判 0；平坦 Δ₀ = 0.3、n = 96 时宣布率 0.98），但对未采样凹陷失效（n = 96 时覆盖 0.22–0.34，Δ₀ = 0.2 时误判 0.17）。它的保证是"采样极值"型的，论文必须如此表述。
3. **GP 同时带在全部四类曲面上覆盖 ≥ 0.91，误判 0，包括未采样凹陷**（后验方差在采样点之间自然增宽）。代价是功效低：平坦 Δ₀ = 0.3、n = 96 时宣布率仅 0.47，且 n 从 48 到 96 几乎不增长。原因是带向采样范围外外推 0.5 且超参数网格含短长度尺度，后验在带端发散；`track_s_smax2/` 配置检验去掉外推后的功效。
4. **平坦性门控没有带来收益。**在 13 个设计点下 GP 已能拟合采样点凹陷，门控只在未采样凹陷上把覆盖率从 0.91–0.98 拉低到 0.89。门控在平坦曲面上的误触发率为 0.16–0.20（4 个配对检验未做多重比较修正），触发后回退到并集界，从而继承了并集界对未采样特征的失效。真实分析 v2 里门控的动机是接触轴只有 3 个点、GP 抹平了茄子摩擦的真实下降；模拟表明在设计点足够时门控应去掉，在 3 点轴上则应改用并集界而不是 GP。

## 对方法论贡献的影响

- 判定阶梯改为两级，并各自标明保证类型：**并集界 = 采样极值保证，高功效；GP 同时带 = 带内保证（平滑先验下），低功效**。三列表中"门控"一列撤掉，接触轴（3 点）直接用并集界。
- 需要补一句关于并集界失效条件的陈述：当 Δ(z) 可能在采样点之间出现宽度小于采样间距的特征时，只有带内保证型方法有效；这正是 5×5×2 回放网格的采样间距（log₂ 0.5）应与策略扫描一致的理由。
- GP 功效问题是可修的：不外推、或把超参数先验限制到与采样间距相称的长度尺度。`track_s_smax2` 的结果决定采用哪种。

## 与真实数据的对应

- 真实 v2 结果中 GP 同时带对茄子给出 [−0.02, +0.34]（拒判）、勺子 [+0.01, +0.46]（下界贴零）：与模拟中 GP 在 n = 48–96、Δ₀ = 0.2–0.3 时宣布率 0.3–0.5 的行为一致，说明真实数据上的拒判部分来自方法功效而非数据本身。
- 真实并集界对勺子拒判（等比 ×2 区间下界 0.00）：模拟中并集界在 Δ₀ = 0.3、n = 48 时宣布率 0.55，也与之相符。

## 补充（02:10）：不外推配置 `track_s_smax2/`（带限制在采样范围 |s| ≤ 2）

| 曲面 | GP 同时带 最小覆盖 / 最大误判 / 平均宣布率（外推 2.5 → 不外推 2.0） | 并集界（不外推配置） |
|---|---|---|
| 平坦 | 1.00 / 0.00 / 0.14 → 0.99 / 0.00 / 0.22 | 1.00 / 0.00 / 0.24 |
| 线性 | 0.95 / 0.00 / 0.15 → 0.96 / 0.00 / 0.17 | 1.00 / 0.00 / 0.19 |
| 采样点凹陷 | 0.97 / 0.00 / 0.04 → 0.94 / 0.00 / 0.07 | 0.98 / 0.00 / 0.03 |
| 未采样凹陷 | 0.91 / 0.00 / 0.08 → 0.85 / 0.01 / 0.15 | 0.22 / 0.17 / 0.21 |

- 功效：平坦 Δ₀ = 0.3、n = 96 的宣布率 0.47 → 0.77；线性 0.30 → 0.65；且随 n 单调上升（外推配置下不上升）。
- 代价：未采样凹陷的最小覆盖 0.91 → 0.85（n = 48 单元），采样点凹陷 0.97 → 0.94。带端外推提供的是对"带外邻近特征"的额外保守性。
- 并集界在同一配置下仍是采样极值保证里功效最高的（平坦 Δ₀ = 0.3、n = 96 宣布率 0.98 vs GP 0.77）。
- 采用建议：论文主表用不外推的 GP 同时带（保证域 = 采样范围内的带），并在方法一节说明覆盖率在"采样间距以下的特征"上降到约 0.85–0.94；下一档改进是把长度尺度先验下限设为采样间距（log₂ 1），预计在不损失采样点凹陷覆盖的前提下再提高功效，留作赛道 S 的下一次运行。

## 补充（12:50）：第三配置 `track_s_smax2_ell1/`（不外推 + GP 长度尺度下限 = 采样间距 log₂ 1）

| 曲面 | GP 同时带 最小覆盖 / 最大误判 / 平均宣布率 | 对照：不外推、无下限 |
|---|---|---|
| 平坦 | 0.99 / 0.01 / 0.40 | 0.99 / 0.00 / 0.22 |
| 线性 | 0.90 / 0.00 / 0.30 | 0.96 / 0.00 / 0.17 |
| 采样点凹陷 | **0.83 / 0.03 / 0.15** | 0.94 / 0.00 / 0.07 |
| 未采样凹陷 | **0.45 / 0.10 / 0.35** | 0.85 / 0.01 / 0.15 |

功效再提高约一倍，但代价是有效性：把长度尺度限制在采样间距以上等于假设曲面在采样间距尺度上平滑，凹陷类曲面正好违反这一假设，覆盖率降到 0.45–0.83、误判 0.03–0.10。结论：**不采用**长度尺度下限；GP 同时带的推荐配置为"不外推、超参数全网格边际化"（第二配置）。这也是一条方法论陈述：响应面法的功效增益只能靠先验换取，先验越强、对未采样特征越脆弱。

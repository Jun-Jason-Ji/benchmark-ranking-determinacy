# 决策相关可辨识性：最小合成实验

状态：2026-09-18 已执行。**这是已知方差、模型正确的二维线性高斯机制验证，不是机器人实验、真机证据、SIMPLER 复现或 VLA 评测。**

本目录只使用 NumPy 与 Python 标准库；未安装全局依赖，未修改 GPU 驱动或系统配置。统计主配置在首轮运行前写入 `config.json`，主种子为 `20260918`，300 次重复。代码没有挑选成功种子、删除失败案例或在结果出现后改动数据分布。后续加上了 Wilson 区间这一描述性不确定度汇总，配置与原始试验保持不变。

## 1. 这个实验回答什么

1. 两套参数能否产生相同校准观测，却让两个策略的期望进度排序相反？
2. 真正未激励方向与很弱但非零的激励方向，随样本量增加是否表现不同？
3. 在有限离线证据池中，经典随机选择、D-opt 与 c-opt 怎样影响排序可判定率？
4. 已知模型条件下，共享参数置信集合与单策略对的经典 Wald 区间是否具有不同效率？

**未实现的主论文部分：** 非线性接触动力学、未知噪声校准、结构偏差估计、响应驱动的自适应选择、新的“可判定性效用”、多策略排序图、VLA rollout、真实日志配对、真机排序外部验证。c-opt 是经典方向信息基线，不能包装成新方法。

## 2. 模型、策略与可核验真值

未知两通道有效增益为 `theta=(theta1,theta2)`，已知物理范围 `[0,1]^2`。观测模型为：

```text
y = x^T theta + epsilon
epsilon ~ Normal(0, sigma^2), sigma = 0.15 (known)
```

把它理解为一个抽象两输入线性执行器：输入 `x` 产生一维位移。候选策略 `pi1` 输入 `(1,0)`，策略 `pi2` 输入 `(0,1)`；期望进度分别为 `J1=theta1`、`J2=theta2`，差值 `Delta=theta1-theta2`。奖励是连续进度，**不使用机器人成功率**。允许符号为负的差分探测输入是这个抽象模型的假设，不能直接移植到机械臂动作空间。

初始 8 条校准输入均为 `s=(1,1)/sqrt(2)`。它只激励增益和，策略差值的方向 `d=(1,-1)/sqrt(2)` 未被激励。

首轮前固定的解析例子：

| 参数 | 校准观测均值 | `Delta` | 真排序 |
|---|---:|---:|---|
| `(0.25,0.65)` | `0.9/sqrt(2)` | -0.40 | pi2 更好 |
| `(0.65,0.25)` | `0.9/sqrt(2)` | +0.40 | pi1 更好 |

两者生成完全相同的初始校准分布。这个例子证明存在性；普遍性实验使用完整随机分布 `theta ~ Uniform([0.1,0.9]^2)`，不是只展示这两个点。

## 3. 有限样本统计语义

令 `A=X^T X`、`theta_hat=A^+ X^T y`、`r=rank(X)`。使用集合：

```text
C_alpha = {theta in [0,1]^2:
  (theta-theta_hat)^T A (theta-theta_hat) <= sigma^2 chi2_r(1-alpha)}
```

在本实验已知方差、线性模型正确、设计与响应噪声独立的条件下，真参数代入左边并除以 `sigma²` 恰为 `chi2_r`，不是渐近近似。rank=1 是椭圆柱与矩形的交集，rank=2 是椭圆与矩形的交集。使用已知 box 不会降低真参数覆盖，因为真参数由设计保证在 box 内。

`model.linear_extrema` 用连续解析候选点计算 `Delta` 的极值：完整椭圆的支持点、椭圆与 box 边的交点、box 顶点，以及退化点。**这不是用稠密网格极值冒充连续空间界**；稠密网格只用于交叉检查。运算仍是浮点计算，不声称完成形式化数值验证。

实践优势阈值 `delta=0.05`。只有区间下界 `>delta` 或上界 `<-delta` 才声明某策略有明确优势；其他情况暂缓排序。空集合单独记录并拒判。

每个预算截面的输入选择只依赖已公开的 `x`，不查看隐藏 `y`，因此保留固定设计置信语义。**没有对任意停止时刻、所有预算同时覆盖或依赖已观察响应的自适应选择提供保证。**

参数覆盖事件推出同一集合传播出的策略差值覆盖，但以下说法不成立：

- 95% 参数集合覆盖意味着所有条件下的经验覆盖率恰好是 95%；
- 95% 参数集合覆盖意味着“已给出结论的样本中错误率不超过 5%”；
- 暂缓排序意味着真实策略差异很小。

正确区别是：在假设成立时，每个固定预算上**无条件错误声明概率**不大于集合失覆盖概率；条件于“有声明”的选择性风险须独立报告。本例 null 场景的真实差值固定为 0.2，却仍长期拒判。

## 4. 离线证据选择协议

有限池包含 `s`、`d`、`e1`、`e2` 四类输入，各 16 条，共 64 条。各方法面对同一组潜在观测，每揭示一条支付一个单位成本。预算为 0、2、4、8、16、32。

- `random`：不放回随机揭示。
- `d_opt`：选择最大化更新后信息矩阵 log determinant 的条目。
- `c_opt`：选择最小化更新后 `g^T A^-1 g` 的条目，`g=(1,-1)`。

选择器使用 `1e-10` 正则项处理初始奇异信息矩阵；**该正则项仅用于选择，不被误当成真实观测信息加入置信集合**。池内数据是真正预先生成的合成结果，算法只看输入元数据，不看隐藏结果。

统计比较同时报告：

- `shared_parameter_set`：从二维参数集合传播得到的差值区间。
- `scalar_wald`：经典单个预设差值正态区间；差值不可估计时返回已知 box 的范围 `[-1,1]`。

第二种对单个预设策略对有效，但不自动具备所有策略对同时覆盖的性质。主实验只有一个策略对，所以它是必须保留的强基线。

## 5. 首轮结果

主阈值为 `alpha=0.05`，每个表格单元包含 300 次重复。可判定率的分母是全部试验，错误声明率同时以全部试验与已声明试验为分母报告。

| 补充预算 | 随机可判定率 | D-opt 可判定率 | c-opt 可判定率 | D-opt / c-opt 平均区间宽度 |
|---:|---:|---:|---:|---:|
| 0 | 0.0% | 0.0% | 0.0% | 1.671 / 1.671 |
| 8 | 37.7% | 51.7% | 51.7% | 0.366 / 0.366 |
| 16 | 50.3% | 59.0% | 60.7% | 0.300 / 0.259 |
| 32 | 61.7% | 63.3% | 63.7% | 0.235 / 0.212 |

**须保留的负面发现：**

1. 预算不超过 8 时，D-opt 和 c-opt 选了完全相同的证据。此实验不能证明方向信息优于经典实验设计。
2. 预算 16 和 32 的 c-opt 与 D-opt 可判定率差异很小，当前没有执行预注册的显著性优越性检验。不能将数值差异写成稳定优势。
3. 预算 8、D-opt 下，经典单差值 Wald 区间的可判定率为 58.7%，共享参数集合为 51.7%。**共享集合不是单个策略对的最优区间构造。** 后续研究必须说明多对同时结论或非线性场景带来什么真实收益。
4. `alpha=0.05` 主配置各预算均未观察到错误声明，但每条件只有 300 次试验，而且并非全部作出声明；不能据此宣称零风险。CSV 给出 Wilson 95% 描述性区间，风险曲线亦保留 `alpha=0.5/0.2/0.1/0.01` 的完整记录。
5. 初始 null 校准下，强制使用最小范数点估计排序（平局固定选 pi1）错误率为 53.7%。这主要反映未激励方向及明确写出的平局规则，不代表所有点估计器在真实机器人上都会失败。

激励机制实验固定 `theta=(0.6,0.4)`，比较样本量从 8 增加到 8192：

| 激励类型 | 差值区间平均宽度 n=8 | n=8192 | 解释 |
|---|---:|---:|---|
| 完全 null | 1.995 | 2.000 | 差值方向从未被观察；继续重复同类数据不能解决 |
| weak（方向强度 0.03） | 1.972 | 0.383 | 非零信息随样本量增加，最终能够改善 |
| balanced | 0.519 | 0.016 | 两个方向都有强信息，区间快速收缩 |

null 情形中，已激励的增益和方向区间宽度由 0.208 降为 0.0065：整体某一方面拟合越来越精确，同时决策相关方向仍未知。weak 情形不能被描述成“再多同分布数据也无效”。

这些结果验证的是已知机制和原型正确性，**没有验证机器人上的现象普遍性或新方法贡献，也不能据此声称达到期刊投稿条件。**

## 8. 对下一阶段的具体约束

1. 保留 scalar Wald 与经典 c-opt，禁止将其删掉来营造新方法优势。
2. 新方法应在经典 c-opt 无法表示的多策略、非线性或不连通相容集场景中定义收益，并先设计可证伪对照。
3. 真实数据中需要另外估计观测噪声、控制时序误差、模型结构偏差；本实验的精确 chi-square 集合不能直接拿来认证未知噪声的机器人仿真。
4. SIMPLER 历史聚合成绩只提供外部标签层；本目录任何数值都不能填入真机实验表。
5. 推进到有限仿真 rollout 时，必须控制 rollout 的随机误差与极值优化误差。本原型的期望奖励解析可得，不涉及 Monte Carlo rollout 误差。
